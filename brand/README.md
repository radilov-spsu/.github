# Логотип организации

| Файл | Назначение |
|---|---|
| `logo.svg` | исходник, 512×512, правьте его |
| `logo-512.png` | растр для аватара организации |
| `logo-64.png` | растр для проверки читаемости в малом размере |

Знак: шестиугольник — граница приложения, три янтарные точки на вершинах —
порты, через которые система разговаривает с внешним миром. Мотив взят
из гексагональной архитектуры («порты и адаптеры»), к которой сводится
инженерная часть курсов.

Цвета: фон `#101827`, контур `#55DDE0`, порты `#FFB84D`.

Композиция вписана в окружность радиусом 210 от центра: GitHub обрезает аватар
в круг, и при правках важно не выносить графику за эту границу.

После правки `logo.svg` пересоберите растры:

```bash
rsvg-convert -w 512 -h 512 logo.svg -o logo-512.png
rsvg-convert -w 64  -h 64  logo.svg -o logo-64.png
```

Проверяйте знак в `logo-64.png`: аватар в списке репозиториев показывается
примерно этого размера, и мелкие детали там пропадают.

Аватар организации загружается вручную:
Settings → Profile → Upload new picture → `logo-512.png`.

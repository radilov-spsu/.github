# Логотип организации

| Файл | Назначение |
|---|---|
| `logo.svg` | исходник, 512×512, правьте его |
| `logo-512.png` | растр для аватара организации |
| `logo-64.png` | растр для проверки читаемости в малом размере |

Знак: три янтарных узла — объекты проектируемой системы, бирюзовые дуги между
ними — связи, три горизонтальные линии — параллельные потоки выполнения.
По одному мотиву на каждый из курсов.

Композиция вписана в окружность радиусом 210 от центра: GitHub обрезает аватар
в круг, и при правках важно не выносить графику за эту границу.

Аватар организации загружается вручную:
Settings → Profile → Upload new picture → `logo-512.png`.

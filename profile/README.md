## Регистрация

1. Заполняете [форму](https://github.com/radilov-spsu/enroll/issues/new?template=enrollment.yml) —
   фамилия, имя, группа.
2. Робот проверяет заявку и отвечает комментарием.
3. Преподаватель подтверждает — вам создаётся личный приватный репозиторий
   вида `ivanov-ivan-2026`.
4. Принимаете приглашения на почте и начинаете работать.

Репозиторий выдаётся один на все предметы: папки курсов уже лежат внутри,
даже если предмет будет у вас только в следующем году.

## Работы сдаются через Pull Request

Не коммитом в `main`. Так замечания привязываются к конкретным строкам кода,
а история сдач видна целиком — и вам, и преподавателю.

Подробные правила — в `README.md` вашего репозитория.
